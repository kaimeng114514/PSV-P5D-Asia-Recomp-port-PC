## M1781 · 2026-11-22 · 键盘按键第一下就把图标切回键鼠

**现象**：用手柄操控时按键盘键（Q/E、Esc、Backspace、Enter 等），操作方式变成键鼠，但屏幕上的按键图标仍是手柄样式。

**根因**：设备切换（重绘键鼠图标）挂在 `p5d_key_event()` 末尾；事件循环里 Q/E、Esc、Backspace、Return、F 键等分支会先 `continue` 把按键消费掉，这些键根本到不了设备切换。

**修复**：在事件循环处理键盘事件的最前面调用 `device_keyboard()`——任何按键按下（非 repeat）都先切回键鼠 UI 并重绘全部图标。

**验证**：主菜单/歌单/COMMU/设置页：手柄操作后按任意键盘键，图标立即变为键鼠样式；再碰手柄图标切回。

## M1780 · 2026-11-22 · 观看模式里按 D / 方向键也能切回键鼠

**现象**：用手柄进入 COLLECTION 观看模式后，按 D 或方向键没被识别，图标与按键映射不切回键鼠。

**根因**：`p5d_key_event()` 里观看模式的按键块位于函数最前并 `return 1` 提前返回，绕过了函数末尾的 `device_keyboard()`。

**修复**：在 `p5d_key_event()` 入口处先调用 `device_keyboard()`，保证观看模式里的提前返回不会漏掉设备切换。

**验证**：手柄进观看模式 → 按 D/方向键：图标切回键鼠，WASD/方向键开始驱动摇杆（移动/旋转）。

## M1779 · 2026-11-22 · 观看模式里切换设备不再让手柄摇杆失效

**现象**：在收藏/观看模式里在手柄、键盘、鼠标之间来回切换，手柄摇杆会失效。

**根因**：观看模式的"WASD=左摇杆、方向键=右摇杆"覆盖逻辑没有判断当前设备，手柄进入观看模式后摇杆值被键盘的零位移覆盖。

**修复**：覆盖逻辑加上 `window_uses_keyboard()` 条件——只有键鼠是当前 UI 设备时才用键盘状态驱动摇杆；手柄操控时摇杆直通游戏（与事件场景 M1658 的规则一致）。

**验证**：手柄进观看模式：摇杆移动/旋转正常；切键盘 WASD/方向键正常；再切回手柄摇杆立刻恢复。

## M1778 · 2026-11-22 · 手柄开关观看模式时同步状态位

**现象**：手柄在 COLLECTION 打开观看模式后，切到键盘时键位映射/图标映射错乱（WASD 被当成菜单键、图标显示成菜单图标）。

**根因**：移植层用 `p5d_collection_watching` 决定观看模式下的键盘映射与键帽图标，但该状态位只在键盘 Enter 路径更新；手柄 START 是游戏自己处理的，状态位没同步。

**修复**：手柄 START（在鉴赏页且深度≥3）切换观看状态位；手柄返回（Circle）退出观看模式时清除状态位。不再对画廊层级做"数按键"式记账（此前的 2026-11-22 构建因此变糟）。

**验证**：手柄打开观看模式 → 切键盘：WASD/方向键驱动摇杆、图标为观看模式键帽；手柄关闭观看模式 → 切键盘：恢复菜单映射。

## M1776/M1777 · 2026-11-22 · 收藏流程 Enter 状态与发布打包

- **M1777（发布打包）**：启动器的 UI 图片（`assets/p5d/*.png` 等）按发布规范不入公开仓库，重新打包时 `stage()` 只复制 git 跟踪文件，导致新启动器丢失背景图、并漏掉 `pipeline/p5d_mods_apply.py`、`dispcapture.c`、`runtime/gfx/*glyphs.h` 等文件。修复：`stage()` 在跟踪文件之后从工作树补拷这些资源/生成源文件。
- **M1776（输入状态）**：观看模式 Enter 防连按锁只在"收藏流程活跃时"的 Return 抬起才清除，手柄期间可能留下锁，导致下一次 Enter 被吞。修复：任何 Return 抬起都清除，并在离开收藏流程时清除。

**验证**：启动器背景、MOD 页、图标资源完整；收藏页 Enter 进/出观看模式稳定。
